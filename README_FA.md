# شاهـاب اسکنر

نرم‌افزار اسکن چندصفحه‌ای اسناد برای اندروید و ویندوز.

## امکانات
- اسکن چندصفحه‌ای با اسکنر ML Kit در اندروید
- ثبت تصویر خام با CameraX و نگهداری جداگانهٔ اصل و نسخهٔ ویرایش‌شده
- انتخاب تصویر، چرخش، فیلتر خاکستری و بازیابی اصل
- خروجی PDF چندصفحه‌ای
- OCR فارسی با مدل Tesseract (در اولین اجرا نیازمند اینترنت)
- ذخیره و بازکردن پروژهٔ قابل‌انتقال `.shahab`
- برنامهٔ دسکتاپ ویندوز با PySide6 و OpenCV

## ساخت
ساخت خودکار در GitHub Actions انجام می‌شود. APK پیش‌فرض debug و بدون امضای انتشار است. برای نسخهٔ تولیدی اندروید باید کلید امضا به‌صورت امن در تنظیمات مخزن اضافه شود.

برای جزئیات ثبت تصویر خام، [راهنما](docs/RAW_CAPTURE_FA.md) و برای کارهای باقی‌مانده [نقشه راه](docs/ROADMAP_FA.md) را ببینید.
