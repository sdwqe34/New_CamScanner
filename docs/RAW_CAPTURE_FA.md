# تصویر خام دوربین

این بخش مسیر جداگانه‌ای برای گرفتن تصویر با CameraX دارد تا فایل اولیه از نسخه‌های ویرایش‌شده جدا بماند.

- تصویر خام به‌صورت مستقل در پروژه ذخیره می‌شود.
- چرخش، خاکستری‌کردن و سایر ویرایش‌ها روی نسخهٔ جداگانه انجام می‌شوند.
- هنگام خروجی گرفتن از پروژه، تصویر اصلی، تصویر ویرایش‌شده و متن OCR هر صفحه در آرشیو `.shahab` قرار می‌گیرند.

## محدودیت
عملکرد نهایی به مجوز دوربین، سازگاری دستگاه و نسخهٔ Android وابسته است؛ پیش از استفادهٔ عملی، روی دستگاه واقعی آزمایش شود.
